主题画廊

怎么跟随主题

图标资源在打包时已按主题渲染好（Resources/AppIconThemes/*.png），运行时只做一次映射。

01 / 选主题

设置里的 7 个圆点

选中后立刻写进 AppSettings.panelThemeID，并发出主题变更通知。

02 / 选图

主题 → 一张 PNG

内置主题取 theme-<id>.png；「跟随系统」按 AppleAccentColor 取 system-<accent>.png。

03 / 应用

Dock 与关于页

设 NSApp.applicationIconImage；关于页读同一张，Finder 与通知横幅仍是 bundle 里的静态 icns。

重新生成：python3 design/icon-web/theme-icons/generate.py → bash Support/render-theme-icons.sh → bash Support/build-app.sh。
